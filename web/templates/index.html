Cách làm cho demo chạy ngay
1) Build index trước (khuyến nghị) để startup nhanh và search chuẩn:
python scripts/build_index.py --data data/vnexpress_articles.csv
2) Sau đó chạy web:
python -m uvicorn web_app:app --reload --port 8000
Hoặc nếu bạn chỉ cần demo nhanh (không NER/KG), bật lite build (lấy N bài đầu):
set ALLOW_LITE_BUILD=1
set DEMO_MAX_DOCS=2000
python -m uvicorn web_app:app --reload --port 8000
